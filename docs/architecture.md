# Projet Gestion Commerciale - Avalonia MVVM

## Architecture

- **Models/** : Client, Produit, Commande
- **ViewModels/** : Logique et binding UI
- **Views/** : XAML Avalonia
- **Data/** : DatabaseConnection
- **Utils/** : fonctions utilitaires

## Fonctionnalités
- Connexion MySQL
- CRUD pour Clients, Produits, Commandes
- Propriétés calculées dans Models
- Test de connexion MySQL
